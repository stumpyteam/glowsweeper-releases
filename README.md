# Glowsweeper test builds

Test builds of **Glowsweeper**, a Minesweeper roguelite by Stumpy Team. Every board can be solved by logic alone.

**Install:** open [the latest release](https://github.com/stumpyteam/glowsweeper-releases/releases/latest) on your Android phone, tap the `.apk`, and allow the install. Later test builds update from inside the app (the **Update** pill on the menu).

These are test builds, not the Play Store version. Each release lists its SHA-256.
